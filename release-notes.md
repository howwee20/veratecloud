# PolySwap live Chat alpha

The public site now loads the PolySwap workspace instead of a marketing page.
It loads OpenRouter's live catalog, supports provider/capability/context/vision
filters, saves favorites and recent models, connects through OAuth PKCE, and
streams real Chat responses with usage and cost metadata.

Hosted Agent execution is intentionally not presented as connected until the
isolated worker, account, durable project, and artifact layers are deployed.
The working OpenCode/OpenRouter agent alpha remains a separate local service.
